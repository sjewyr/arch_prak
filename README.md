## Запуск

```
   docker-compose up --build
```

## Добавление и синхронизация данных в хранилищах

**Изменяя env CREATE_DATA в контейнере sync в файле docker-compose.yaml перед запуском - можно указать нужно ли применять дамп к PostgreSQL и копировать данные из него в другие хранилища**  

```
    CREATE_DATA=1  # записываем данные (нужно при первом запуске)
    CREATE_DATA=0  # пропускаем шаг с записью данных
```
